[ How it works ]

Three steps between you and a clean repo.

STEP 01

Install once

One package from PyPI or npm. No Python required for the npm build — it ships self-contained.

$ uv pip install lintro
STEP 02

Run one command

Lintro detects your tools and native configs automatically. Nothing to migrate, nothing to relearn.

$ lintro check .
STEP 03

Report anywhere

Grid in your terminal, SARIF in GitHub code scanning, HTML for stakeholders — from the same run.

$ lintro check --output-format sarif
