what we believe

01

unified, not uniform

One command surface for 32 ecosystem tools — but every tool stays native underneath. No rewrites, no wrappers that swallow flags. → browse the tool matrix

02

your configs stay

pyproject.toml, .prettierrc, .yamllint — detected in place, respected as-found. Migration theatre is a bug, not a feature. → read the config guide
