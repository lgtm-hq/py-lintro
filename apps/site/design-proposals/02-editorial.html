The unification issue

Every linter in your stack, finally speaking one language.

Lintro is a comprehensive CLI that unifies formatting, linting, and testing under a single interface. It reads the configs you already keep — nothing to migrate, nothing to relearn — and answers in six report formats.

$ lintro check . Read the docs

“One command to learn. Thirty-two tools already fluent.”

— The Editorial Board
